# Maintenance and feedback

This repository is maintained, tested, and released independently. The other language edition is not required. See LICENSE for rights; code contributions are not accepted without a separate permission agreement. Report reproducible issues without customer data, personal information, or secrets; include version, OS, host, and expected behavior.

Maintainers follow [release instructions](docs/releasing.md). Synchronize only the explicitly shared copies within this repository. Preserve historical rendering evidence; store new results under a new version directory.
