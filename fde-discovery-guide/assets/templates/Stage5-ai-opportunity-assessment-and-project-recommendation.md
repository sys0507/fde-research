# Stage 5: AI Opportunity Assessment and Project Recommendation

## 1. The business work most worth improving right now

Review the problem, the current handling method, the cause, the baseline, and the available materials in terms of concrete role actions. Distinguish the extra labor that should change from necessary controls and normal waiting.

## 2. Candidate improvement directions

Think in terms of information foundation building, decision support, and automation with clear boundaries; they can be combined, and there is no requirement to build all three layers. First compare how much process change, rules, or ordinary system integration can achieve, then state what AI adds.

## 3. Recommended and deferred directions

State directly the work to take up first, the reason for recommending it, how it connects to the existing flow, and the judgment left to people. An ordinary system improvement may be part of the recommendation. Propose an ontology only where unified objects, relations, states, and rules are needed — never as a default purchase item.

State the directions deferred and why, avoiding a write-up that lists only risks and to-dos without a judgment for this round. Without an implementation trial, do not promise an improvement percentage, an ROI, or a model accuracy figure.

## 4. Focus of later verification

Around the recommended direction, list the business results, handling burden, reliability, and enabling conditions that need verification. Make clear which baseline definitions carry over and where materials still need to be collected. Detailed technology selection, responsibilities, and the development delivery plan belong to the later solution phase.

## 5. Deliverables and continued use

Link the current five stage documents, the complete asset inventory, the field dictionary, the baseline inputs and results, and the final report. State the version and the unresolved gaps; never let an old report be treated automatically as current fact. The user may continue the investigation, revise the recommendation, or export the current version of the deliverables.
